# 625 英文學習法｜LLM Wiki 作業

此資料夾可直接作為 GitHub 儲存庫的根目錄。

## 上傳方式

1. 在 GitHub 建立新的 repository，例如 `625-english-llm-wiki`。
2. 將本資料夾內的所有檔案與資料夾上傳到 repository 根目錄，不要只上傳 ZIP 檔。
3. 進入 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇 `main` branch 與 `/(root)` 資料夾，然後按 **Save**。
6. 等待 GitHub Pages 發布後，即可使用顯示的網址提交作業。

## 內容

- `index.html`：作業首頁。
- `slides/index.html`：教學型 HTML 簡報。
- `wiki/`：LLM Wiki 的索引、概念頁、來源頁、整合摘要與討論紀錄。
- `rawpaper/`：原始 PDF 資料與來源登錄。
- `rawweb/`：影片與官方網頁的原始來源登錄。
- `AGENTS.md`：Wiki 維護、ingest、檢查與簡報產生規則。
- `log.md`：實際執行與檢查紀錄。

主題：625 英文學習法。對象為已有英文基礎、但容易忘記單字的學習者。

本專案已 ingest 5 份資料：625 字表、介紹影片、官方說明、發音教學研究與間隔複習研究。簡報內容只使用 Wiki 中已整理的資訊，並在投影片標記來源代號。
